# Expense Tracker 💰
A Python-based Expense Tracker developed as part of my programming learning journey.

# About
This project is a terminal-based Expense Tracker built using Python. It allows users to record and manage their daily expenses by entering 
details such as the expense category, amount, and description. The project was built to strengthen my understanding of programming 
fundamentals, data management, user input handling, functions, file handling, and problem-solving.

# Features
- Add new expenses
- Record expense amount
- Record expense category
- Add expense descriptions
- View recorded expenses
- Store expense records
- Calculate total expenses
- Categorise expenses
- User input handling
- Terminal-based interface
