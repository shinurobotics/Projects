# Calculator 🧮
A Python-based Calculator developed as part of my programming learning journey.

# About
This project is a terminal-based Calculator built using Python. It allows users to perform basic mathematical calculations by entering numbers and selecting an operation.
The project was built to strengthen my understanding of programming fundamentals, user input handling, conditional statements, functions, mathematical operations, and problem-solving.

# Features
- Addition
- Subtraction
- Multiplication
- Division
- User input for numbers
- Operation selection
- Calculation results
- Basic mathematical operations
- Terminal-based interface
